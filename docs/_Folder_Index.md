# SeatWatcher docs 인덱스

`docs/`는 외부 소개용 문서가 아니라 사용자와 ChatGPT가 함께 개발하면서 요구사항, 판정 규칙, 구현 방향, 검증 결과를 맞추기 위한 협업 문서 공간이다.

- `00_프로젝트_설계기준.md`: 현재 요구사항, 아키텍처, 설정 분리, Git 운영, 좌석 변동 알림·polling 성능 규칙, 검증 기준을 유지하는 개발 협업 SSOT
- `01_작업일지.md`: 채팅 간 작업 인수인계용 Markdown 작업일지. 최근 완료, 검증 결과, 로컬 커밋·무결성 게이트 상태, 다음 작업을 기록하며 새 채팅에서 설계기준과 함께 먼저 읽는다.
- `*.gdoc`: Google Drive 데스크톱이 만들 수 있는 로컬 포인터이며 문서 원문이 아니다. 기존 `01_작업일지.gdoc`는 삭제했고, 재생성되는 `.gdoc`도 공개 Git에서는 제외한다.

외부 사용자에게 보여줄 프로젝트 소개·기능 설명·실행 방법은 루트 `README.md`에서 관리한다.

제품 코드 변경 전 설계기준을 먼저 대조한다. 실제 개인 일정·정확한 생활권 목적지·인증정보는 저장소 문서에 기록하지 않는다. 실제 감시 일정은 Git 제외 `watch_targets.local.json`, 실제 비밀값은 Git 제외 `.env.local`에 둔다.

SeatWatcher의 일반 개발 흐름은 로컬 수정 → 관련 검증/빌드 성공 → 기존 Git 커밋 스킬에 따른 로컬 자동 커밋이다. GitHub push는 사용자에게 원격 반영 지시를 받았을 때만 누적 커밋을 대상으로 수행한다.
